O que é teste de software?

01

O teste de software é uma das partes mais importantes do desenvolvimento, pois é nele que verificamos se o sistema está funcionando corretamente. É possível identificar erros, falhas e verificar se todos os requisitos do projeto foram atendidos antes de o sistema ser entregue ao usuário.

Qual a importância de testar?

02

É importante testar um software, pois isso evita que o usuário encontre erros ao utilizá-lo e também garante que todas as suas funções estejam funcionando corretamente. Quando a etapa de testes não é feita, é provável que o software tenha falhas, e isso pode acabar prejudicando a empresa e até mesmo os usuários.

Exemplos de sistemas que falharam

03

Aeroporto de Denver – O sistema de bagagens apresentou vários erros durante os testes. Algumas malas iam para o lugar errado, outras eram danificadas e o sistema apresentava muitas falhas. Por causa disso, ele não pôde ser implantado e precisou passar por várias alterações antes de começar a funcionar.

Target – Criou um sistema para controlar o estoque das lojas, mas ele teve vários problemas. Alguns produtos apareciam como disponíveis, sendo que na verdade não estavam no estoque. Por causa dessas falhas, a empresa teve muitos prejuízos.

Tipos de teste de software

04
Teste Unitário Testa uma parte do sistema para ver se ela funciona.
Teste de Integração Verifica se as partes do sistema funcionam quando são ligadas entre elas.
Teste de Sistema Testa o sistema inteiro para conferir se está tudo funcionando.
Teste de Aceitação É feito para saber se o sistema está do jeito que o cliente pediu.
Teste de Desempenho Verifica se o sistema é rápido e se consegue funcionar bem com vários usuários.
Teste de Segurança Serve para verificar se os dados dos usuários estão protegidos e se o sistema é seguro.
Teste de Regressão É feito depois de alguma mudança no sistema para verificar se nada que já funcionava parou de funcionar.
